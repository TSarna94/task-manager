# Task Manager

## Overview

Task Manager is a command-line application built in Python that allows users to manage tasks, assign work to team members, track progress, and generate performance reports.

The project includes user authentication, task tracking, reporting, and statistical analysis, providing a practical demonstration of file handling, data management, and application logic.

## Features

### User Management

- User registration
- Login authentication
- Prevention of duplicate usernames

### Task Management

- Create new tasks
- Assign tasks to users
- Edit existing tasks
- Mark tasks as completed
- View all tasks
- View user-specific tasks

### Task Monitoring

- View completed tasks
- View overdue tasks
- Sort tasks by:
  - Due date
  - Assigned user
  - Completion status

### Reporting

- Generate task overview reports
- Generate user performance reports
- Display task statistics
- Track completion and overdue percentages

## How It Works

The application stores user and task information in text files and allows authenticated users to manage tasks through a menu-driven interface.

Users can:

- Register new accounts
- Create and assign tasks
- Update task details
- Monitor task completion
- Generate summary reports
- Track overdue work
